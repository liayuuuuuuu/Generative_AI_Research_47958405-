2.File Storage Methods
Survey data, interview transcripts, consent forms, and photos or other media containing identifiable participant information require special access controls. Access should be restricted to authorised research team members because these files may contain personal, sensitive, or confidential information. I think clear and consistent filenames make it easier to identify, sort and find files. Including a topic, date or version number also helps avoid confusion between different copies.
